Browser demo for the Infinitic AI Urdu headline classifier.

Loads quantized ONNX weights from `/models/urdu-headline/` on this Space via
Transformers.js (no Hugging Face token). Model files are hosted on the Space
because Hub Xet CDN downloads of the large ONNX file were failing in-browser
with `network error`.
